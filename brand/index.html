Naming

“Kinetiq” is a single word, always spelled with a capital “K” and ending with a lowercase “q”. It is never set in all caps in running text.

Write

  • Kinetiq
  • kinetiq.xyz

Don’t write

  • KinetiQ
  • Kinetic
  • KINETIQ
